How to read this review

Threadline reads your Python source. It never runs it, so every link below is what the code says, not what happened at runtime. Tests are linked the same way; they are not run and coverage is not measured.

How sure a link is

Calls
The source names exactly one method.
Probably calls
The likely target, but inheritance, decorators, or a reassignment could change it.
Library
Code outside this repository, such as the standard library or a dependency.
Can't tell
The target is decided at runtime, for example a callback or a dynamic attribute.

Moving around

Selecting anything shows its code on the right. Go to → opens that method, and the path bar above the title leads back.
