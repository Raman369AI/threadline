Instructions

Source only, not executed. Threadline reads your Python source. It never runs it, so every link below is what the code says, not what happened at runtime. Tests are linked the same way; they are not run and coverage is not measured.

How sure a link is

Calls
The source names exactly one method.
Probably calls
The likely target, but inheritance, decorators, or a reassignment could change it.
Library
Code outside this repository, such as the standard library or a dependency.
Can't tell
The target is decided at runtime, for example a callback or a dynamic attribute.

Call map tags

if
Runs only when a condition holds.
later
Created now, runs later if at all (an unawaited coroutine or a generator).
probably
The likely target; inheritance or a reassignment could change it.
can't tell
The target is decided at runtime.
new object
Creates an object; its initializer runs.

Reading a method

The summary lists what comes in, the functions it calls, what it changes, what it returns, and what it raises. Calls also include methods on objects passed in, such as db.commit or repository.save; they are dashed when the target cannot be told from source. A dashed item is uncertain: a call that probably goes there, or a change a called function might make. Select a name to highlight every use; assignments show in bold. Select an underlined call, a test, or a caller to read it beside the code, and Open → to move into it. ← Back returns.
