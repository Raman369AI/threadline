# Start from the whole project

**Review Workspace** opens a catalog of what the project does:

- **Endpoints**: HTTP routes, grouped by the file that declares them.
- **Commands & tasks**: command-line entry points and background tasks.
- **Modules & methods**: a folder tree in the sidebar and a card for every module.

Hover a row to preview its parameters, effects, linked tests, and callers; select it to open its review.
