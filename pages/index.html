Questions

What is Threadline?

Threadline is a free, open-source code review tool. It maps a project's endpoints, CLI commands, and methods, then shows each method's calls, inputs, effects, returns, tests, and callers next to the original source.

Is it really free?

Yes, free forever. No account, no sign-up, and no usage limits beyond what your browser can handle.

Who is it for?

Developers reviewing unfamiliar code, and vibe coders who built something with an AI assistant and want to understand what it actually does before they ship it.

Which languages are supported?

Python today, including web apps with HTML or Jinja templates. More languages are on the way.

Does my code leave my browser?

No. Files are fetched directly from GitHub and analysed on your device. Nothing is uploaded to a separate analysis service, and repository code is read as source, never executed.

Can I use it locally or on private code?

Yes. Install the threadline-review package and run the local CLI. It also reviews changes between Git revisions, which the browser version does not.

Is there a VS Code extension?

Yes. Install Threadline — Python Review from the Visual Studio Marketplace to open the function at your cursor, workspace methods, or Git changes in an editor panel. It requires Python 3.12 or later.
