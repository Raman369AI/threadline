# Review the function you are reading

Put the cursor inside a Python function and select the **Threadline** button in the editor title
bar, or the **Threadline** item in the status bar.

The review opens beside your editor with the function's original code, what it takes in and
returns, the project methods it calls, the effects it reaches, its tests, and its callers.

- Select an underlined call to read that method beside the code.
- **Called by** and **Calls** list callers and callees; **Previous** and **Next** step through the file.
- **Open in editor** jumps to the source.
